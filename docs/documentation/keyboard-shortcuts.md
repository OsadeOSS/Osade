# Keyboard shortcuts

Osade uses `Ctrl` on Windows and Linux and `Cmd` on macOS. Global shortcuts work unless a dialog
or text editor needs the same keystroke.

| Action | Windows/Linux | macOS |
| --- | --- | --- |
| Open command center | `Ctrl+K` | `Cmd+K` |
| Start a new chat | `Ctrl+T` | `Cmd+T` |
| Close the current tab | `Ctrl+W` | `Cmd+W` |
| Switch to open tab 1–9 | `Ctrl+1` … `Ctrl+9` | `Cmd+1` … `Cmd+9` |
| Open or close Browser view | `Ctrl+Shift+B` | `Cmd+Shift+B` |
| Capture a quick note | `Ctrl+Shift+N` | `Cmd+Shift+N` |
| Open or close Notes | `Ctrl+Shift+Q` | `Cmd+Shift+Q` |
| Approve the visible gate | `Ctrl+Enter` | `Cmd+Enter` |
| Deny the visible gate | `Ctrl+Backspace` | `Cmd+Backspace` |
| Previous/next conversation | `K` / `J` | `K` / `J` |
| Chat, Files, Checks, Diff, Rules, Notes | `1` … `6` | `1` … `6` |

## Composer

| Action | Shortcut |
| --- | --- |
| Send | `Enter` |
| Add a new line | `Shift+Enter` |
| Choose a mention suggestion | Arrow keys, then `Tab` or `Enter` |

When an agent is still working, Enter queues the composed message for delivery when the lane is
ready.

## Command center

Use Up and Down to move through matching actions, Enter to open the selected item, and Escape to
close the command center.

## Quick-note editor

Enter saves a quick note, Shift+Enter adds a line, and Escape dismisses the capture window.
